あそび方
  1. 対戦モードを選びます。コンピューター対戦では強さを選べます。あなたが黒、コンピューターが白です。
  2. 黒から交互に置きます。2人対戦では、黒と白を決めて端末を交代で使います。
  3. 自分の石で挟むと、間にある相手の石がひっくり返ります。縦・横・斜めのすべてが対象です。
  4. 置けないときは自動でパスします。
  5. 2人とも置けなくなったら終了。石が多いほうの勝ちです。
