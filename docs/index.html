あそび方
  1. 対戦モードを選びます。コンピューター対戦では強さを選べます。あなたが黒、コンピューターが白です。
  2. 黒から交互に置きます。2人対戦では、黒と白を決めて端末を交代で使います。
  3. 自分の石で挟むと、間にある相手の石がひっくり返ります。縦・横・斜めのすべてが対象です。
  4. 置けないときは自動でパスします。
  5. 2人とも置けなくなったら終了。石が多いほうの勝ちです。

ルールと駒の動き

先手・後手が交互に指します。相手の王が逃げられない「詰み」を目指します。駒の向きが進む方向です。

敵陣の3段に入る・出る・その中で動くと成れます。金と王は成れません。歩・香が一番奥、桂が奥の2段に進む場合は自動で成ります。

持ち駒は空きマスに打ちます。二歩、打ち歩詰め、行き場のない駒、王手放置になる手は選べません。

同一局面4回は千日手。連続王手の場合は王手を続けた側の負けです。両方の王が敵陣に入った持将棋は、詰ませる見込みがないことを確認して24点法で判定できます。入玉宣言法・持ち時間は採用していません。

王（おう）は、周りの8方向へ1マス進めます。相手の駒に取られる場所には進めません。

飛（ひ）は、縦と横へ何マスでも進めます。ほかの駒は飛び越せません。

角（かく）は、斜めへ何マスでも進めます。ほかの駒は飛び越せません。

金（きん）は、前・横・後ろと斜め前へ1マス進めます。斜め後ろには進めません。

銀（ぎん）は、前と斜め前・斜め後ろへ1マス進めます。真横と真後ろには進めません。

桂（けい）は、2マス前の左右にジャンプします。途中に駒があっても飛び越せます。

香（きょう）は、前へまっすぐ何マスでも進めます。ほかの駒は飛び越せません。

歩（ふ）は、前に1マス進みます。後ろには戻れません。
